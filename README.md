# Делом

**Опыт, подтверждённый делом.** Карьерная платформа для студентов: реальные проекты компаний, подтверждённые навыки, резюме с ИИ-разбором, тренажёр интервью и отклики — в одном месте.

🔗 Демо: https://sanminkim.github.io/delom/

Это кликабельный прототип (MVP) без сервера: всё работает в браузере, данные демо хранятся у каждого посетителя локально.

## Как устроен проект

Исходники лежат по частям в `src/`, а скрипт `build.sh` склеивает их в один файл `index.html` — его и показывает GitHub Pages.

```
./build.sh        # собрать index.html из src/
```

После сборки закоммитьте `index.html` вместе с изменениями в `src/`. GitHub сначала прогонит тесты, и только если все прошли — обновит сайт (около 5 минут).

## Тесты

В `tests/` — автотесты на Playwright, которые открывают сайт в настоящем браузере и проходят продукт как пользователь:

| Файл | Что проверяет |
|---|---|
| `test_projects.py` | Полный цикл каждого из 11 проектов: участие → задачи → решение с файлом → проверка ментора → подтверждённые навыки → портфолио → приглашение; возврат на доработку, отзыв решения, своя команда, проект, опубликованный работодателем |
| `test_features.py` | Разбор резюме (TXT и PDF), профиль и публичная страница, консультация и курс подтверждают навык, разбор резюме ментором, приглашение кандидата, смена тарифа, отчёт и курс вуза, видеовизитка |
| `test_career_tools.py` | Резюме, интервью, письма, отклики — со встроенным анализом и с ИИ |
| `test_all_screens.py` | Все 50 экранов всех ролей: нет ошибок JS, `undefined`/`NaN`, «заглушек»; каждая кнопка на каждом экране работает; на телефоне ничего не вылезает за экран |

Запуск:

```
pip install -r tests/requirements.txt
playwright install chromium
./build.sh && pytest tests -n 4
```

Правило продукта: если кнопка есть — она доводит дело до конца. Тест `test_every_button_works` падает, если какое-то действие показывает «появится позже» или похожую заглушку.

## CI

`.github/workflows/ci.yml` на каждый push и pull request собирает `index.html`, проверяет, что он совпадает с `src/`, и прогоняет все тесты. Сайт на GitHub Pages публикуется только из `main` и только после зелёных тестов.

## Стек

Чистый HTML, CSS и JavaScript без фреймворков и зависимостей. Роутинг через `#hash`, анимации на CSS и View Transitions API, поддержка тёмной темы и `prefers-reduced-motion`.
