# Делом

**Опыт, подтверждённый делом.** Карьерная платформа для студентов: реальные проекты компаний, подтверждённые навыки, резюме с ИИ-разбором, тренажёр интервью и отклики — в одном месте.

🔗 Демо: https://sanminkim.github.io/delom/

Это кликабельный прототип (MVP) без сервера: всё работает в браузере, данные демо хранятся у каждого посетителя локально.

## Как устроен проект

Исходники лежат по частям в `src/`, а скрипт `build.sh` склеивает их в один файл `index.html` — его и показывает GitHub Pages.

```
./build.sh        # собрать index.html из src/
```

После сборки закоммитьте `index.html` вместе с изменениями в `src/` — сайт обновится примерно через минуту.

### Файлы в `src/`

| Файл | Что внутри |
|---|---|
| `00-head.html` | Заголовок страницы, подключение шрифта Onest |
| `07-pwa.html` | Иконка, цвет шапки, манифест для установки на телефон |
| `01-base.css` | Базовые стили: цвета светлой и тёмной темы, кнопки, карточки, сетки |
| `02-extra.css` | Стили разделов: резюме, интервью, отклики, графики, лендинг |
| `03-mobile.css` | Мобильная версия: нижнее меню, шторки, крупные кнопки |
| `60-body.html` | Каркас страницы |
| `10-data.js` | Демо-данные: навыки, треки, проекты, вакансии, компании, тесты |
| `20-core.js` | Состояние, роутер, расчёты (готовность, совпадение), шапка и меню |
| `30-student.js` | Экраны студента: главная, путь, навыки, проекты, вакансии, портфолио |
| `33-ai.js` | Слой ИИ: живой Claude в артефакте, встроенный анализ как запасной |
| `34-resume.js` | Резюме: конструктор, анализ, версии под вакансию, английский, hh.ru |
| `36-career.js` | Интервью, банк историй STAR, письма, отклики, офферы, зарплаты |
| `40-roles.js` | Кабинеты работодателя, ментора, вуза, метрики, вход |
| `46-landing3.js` | Стартовая страница (лендинг) с анимациями |
| `50-actions.js` | Модальные окна и действия пользователя |
| `55-actions2.js` | Промпты для ИИ и действия новых разделов |
| `58-mobile.js` | Логика мобильной версии |
| `99-init.js` | Запуск приложения |

Порядок подключения JS важен и задан в `build.sh`.

## Стек

Чистый HTML, CSS и JavaScript без фреймворков и зависимостей. Роутинг через `#hash`, анимации на CSS и View Transitions API, поддержка тёмной темы и `prefers-reduced-motion`.
